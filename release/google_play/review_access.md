# Google Play review access

Keepi requires authentication for most functionality.

Before submitting for review, create one permanent reviewer account in Firebase Authentication using Email/Password.

Recommended reviewer email:
keepi.review@gmail.com

Do NOT store the password in Git or in this file.

Play Console > App content > App access:
- Select: All or some functionality is restricted
- Instruction:
  1. Sign in with the supplied email and password.
  2. Accept the Keepi Terms of Use on first sign-in.
  3. Home, My Things, Add, Explore, Messages and Profile are then available.
- Confirm that the account has no 2FA, OTP, geo restriction, or expiring password.
