# Keepi roadmap

## Build 1 — Foundation

- Flutter project for Android, iOS and Web/PWA
- App shell and navigation
- Theme
- Firebase dependencies
- Security-rule baseline
- Domain models

## Build 2 — My Things

- Firebase Authentication
- Camera/gallery photo
- Firebase Storage upload
- Create Thing in Firestore
- My Things stream
- Thing details/edit/delete

## Build 3 — AI recognition

- Send image for vision analysis
- Structured result
- Suggested name/category/brand/model
- User confirmation
- Multiple candidate handling

## Build 4 — Marketplace

- Listing separate from Thing
- Sell
- Rent
- Borrow
- Give
- Visibility rules

## Build 5 — Search / Nearby

- Natural-language need
- Category and mode filters
- Geohash/distance
- List and map views
- Availability

## Build 6 — Need requests

- "I need..."
- Match requests to nearby Things
- Owner opt-in notifications

## Build 7 — Transactions

- Rental/sale request
- Approval
- Time window
- Handover/return
- Ratings

## Build 8 — Keepi Price

- New-price estimate
- Used-value estimate
- Hour/day/week rental estimate
- Transaction price history
- Supply/demand signals

## Build 9 — Perishables

- Expiry
- Opened date
- Notifications
- Suggested dynamic price
- Give-away near expiry

## Build 10 — High-value modules

- Deposits
- Identity verification
- Damage evidence
- Insurance integration
- Vehicles
- Property
